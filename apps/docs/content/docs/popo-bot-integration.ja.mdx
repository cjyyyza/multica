POPO は Windows 上の DJ01Bot TypeScript ブリッジを通じて、Multica の共有会話・タスクエンジンに接続します。Windows プロセスが POPO 接続を持ち、ワークスペース限定の資格情報を使用します。

手順の詳細は [英語版](/popo-bot-integration) と [中国語版](/zh/popo-bot-integration) を参照してください。

1. Multica でワンタイムのペアリングコードを発行します（owner/admin）。
2. Node.js 22.5 以降を用意し、DJ01Bot ルートで `npm --prefix ts ci` と `npm --prefix ts run build` を実行します。その後 `node ts/dist/multica-bridge.js pair` と `run` を実行します。引数は詳細手順を参照してください。
3. オンラインの Windows ブリッジと空いているロボットをエージェントに接続します。

サーバー側のスイッチは `MULTICA_POPO_ENABLED=true` です。`multica popo gateway` は削除されました。

既存タスクは `/reply`、`/status`、`/stop` で操作できます。`/yixiezuo preview` と `show` で内容を確認し、`import --confirm` で未割り当てのタスクを作成します。`publish` はレビューを作り、同じメンバーが同じチャットで `confirm` して初めて結果を反映します。レビューは 15 分で期限切れになり、タスクや元データの更新後は再確認が必要です。
