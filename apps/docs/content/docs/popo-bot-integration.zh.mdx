POPO 的产品面和飞书一样（IM 通道 + 共享引擎）。Windows 进程持有 POPO 连接，用工作区限定的通道凭证连 Multica。服务端不会打开 POPO、popo-cli 或 dj01bot。

一个 dj01bot 机器人对应一个 Multica 智能体。`robot_id` 取自本机 `~/.dj01bot/config.json` 的 `websocketRobots[].id`，默认是 `default`。

## 开始之前

- 工作区 owner 或 admin 在 Multica 创建一次性配对码。
- 这台 Windows 上已能独立跑通 dj01bot（`start.bat` / `dj01bot gateway`）。
- 自托管需设置 `MULTICA_POPO_ENABLED=true`。

<Callout type="info">
`multica popo gateway` 已移除，改用 `python -m nanobot.multica_bridge`。
</Callout>

## 1. 配对 Windows 通道

1. 在 Multica 创建一次性配对码（owner/admin）。
2. 在 Windows 上：

```bash
python -m nanobot.multica_bridge pair --server https://your-multica.example --pairing-code <code>
python -m nanobot.multica_bridge run --server https://your-multica.example
```

配对成功后把 `{server, bridge_id, token, workspace_id}` 写到 `%LOCALAPPDATA%/dj01bot/multica-bridge/`。保持 `run` 运行，心跳超过 45 秒会显示离线。

## 2. 把机器人连到智能体

1. 打开 **智能体**，选一个智能体，进入 **集成**。
2. 选择在线的 Windows 通道，以及空闲机器人（已连接且未被 dj01bot/Sparse 占用）。
3. 点击 **连接**。

一个机器人只能绑定一个有效的 Multica 智能体。

## 首次使用与账号绑定

成员第一次找机器人说话时，会收到一次性绑定链接（`/popo/bind?token=`）。打开、登录同一工作区，再回到 POPO 重发消息。链接 15 分钟过期。

## 怎么用

### 私聊

直接发文字，不需要 @。

### 群聊

在群里 @ 机器人发起请求。引用已关联任务的回复可以继续评论同一条任务。媒体附件和 Windows 扫码开通也有对应的桥接流程。

### 命令

- `/new`、`/clear` 走共享引擎，和飞书一样。
- `/issue <标题>` 建 Multica 单（`origin_type=popo_chat`）。
- `/reply 任务编号 <评论>`、`/status 任务编号` 和 `/stop 任务编号` 操作已有任务。停止运行与任务状态分别记录。
- `/yixiezuo preview <工单链接>` 读取单张易协作工单。在本机以发送者绑定的同一个 Multica 成员账号运行 `multica yixiezuo bridge --workspace-id <工作区 UUID>`。
- `/yixiezuo show <操作 ID>` 查看来源材料或处理结果。
- `/yixiezuo import <工单链接> [--project <项目 UUID>]` 直接导入一张易协作工单。本机桥读完后机器人会回报成功或失败；任务保持未分配，不会自动开跑智能体。重复导入保留已有任务和已建立的通知路由。
- `/yixiezuo import <预览 ID> --confirm --project <项目 UUID>` 在预览确认后再导入。
- `/yixiezuo refresh 任务编号` 刷新来源快照，保留本地任务字段。
- `/yixiezuo publish 任务编号 [--status <来源状态>]` 的下一行填写结果与验证证据，先生成待复核内容；再发送 `/yixiezuo confirm <复核 ID>` 排队回写。确认在 15 分钟内有效，绑定同一成员、机器人、聊天、任务版本和来源快照。

导入时所选项目可以关联 `perforce_depot` 资源。成员分配任务后，运行会收到该项目的 P4 上下文。任务评论和运行结果回到原聊天；向易协作回写结果仍需单独确认。

## 管理连接

**设置 → 集成 → POPO** 可查看通道和机器人。owner / admin 可以立即撤销通道凭证。断开机器人后该智能体不再收发 POPO，Multica 会话会保留。

## 自托管

```dotenv
MULTICA_POPO_ENABLED=true
```

未设置或不是 `true` 时，管理接口返回 `configured: false`，Windows 通道接口返回 `503 popo_not_configured`。

`popo-cli` 是登录用户身份（给别的 Windows 工具用），不是这条机器人通道。
